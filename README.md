# 秤量計算 PWA

元のXcode版 weighting の元素データと計算式を移植した、オフライン対応の秤量計算アプリです。ビルド・npm・サーバー処理は不要です。

## GitHub Pagesで公開する

1. GitHubで新しいリポジトリ `weighting-pwa` を作成します。GitHub Freeなら **Public** を選び、**Add README**を有効にします。
2. このフォルダ内のファイルと `icons` フォルダを、リポジトリの **Add file → Upload files** からアップロードします。ZIP自体はアップロードせず、先に展開してください。`index.html` がリポジトリ直下に来るようにします。
3. **Commit changes** で保存します。`.nojekyll` は任意です。Finderで見えなくても、この構成では省略できます。
4. **Settings → Pages → Build and deployment** で **Source: Deploy from a branch / Branch: main / Folder: / (root)** を選び、**Save** を押します。
5. 公開完了後、同じ画面の **Visit site** を開きます。通常のURLは `https://ユーザー名.github.io/weighting-pwa/` です。独自ドメインは不要です。
6. iPhoneのSafariでURLを開きます。共有メニュー → **ホーム画面に追加** → 表示される場合は **Webアプリとして開く** を有効にして追加します。
7. ホーム画面から開き、画面下部が **オフラインで利用できます** になるまでオンラインで待ちます。その後、機内モードでアプリを閉じて開き直し、計算できることを確認してください。

GitHub Pages設定: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

すべてのパスは相対パスです。リポジトリ名を変えても、そのサブディレクトリ内で動作します。Xcodeのファイルや証明書をアップロードする必要はありません。

## 計算・入力

- 初期値: Gd : Ru : Si = 1 : 2 : 2、Gd = 1.00000 g。
- 必要質量 = (対象のモル比 / 基準のモル比) × (基準質量 / 基準の原子量) × 対象の原子量。
- 基準質量と基準のモル比は正の数、ほかのモル比は0以上。空欄や不正値は計算結果を「—」にして通知します。
- 小数点のカンマ入力は小数点として扱います（`1,25` = `1.25`）。桁区切りのカンマは使わないでください。
- 質量は小数点以下5桁に丸めて表示。合計は丸める前の値から計算します。表示桁数は原子量や秤量精度を保証するものではありません。
- 元素ボタンで周期表を開き、横スクロールして選択できます。行追加時の初期元素Ac・モル比2は元のSwift版と同じです。
- 基準は行固有のIDで保持します。基準以外の行を削除しても基準は変わりません。基準行を削除した場合は残りの先頭行が新しい基準になり、指定質量を引き継ぎます。
- 118元素の原子量と周期表配置は元のContentView.swiftからそのまま抽出。原子量の最新版への更新は行っていません。標準原子量のない元素には代表的質量数を使用。純度、同位体組成、酸化物原料などの補正はありません。

## 保存・オフライン

入力は端末のlocalStorageに自動保存されます。外部への入力送信、解析ツール、外部フォント、外部ライブラリは使用していません。Webファイルの配信にはGitHubへの通信が発生します。

HTTPS（または開発時のlocalhost）で初回表示し、必要ファイルの保存が完了するとオフラインで動きます。`index.html`をダブルクリックするだけでは動きません。

7日間の署名期限や開発者年会費はありません。ただし、端末のWebサイトデータ削除やストレージ整理で入力・キャッシュが消える場合があります。その場合は公開URLをオンラインで開き直してください。Safariとホーム画面アプリで保存内容が共有されない場合があるため、日常利用はホーム画面アプリに統一してください。Xcode版から入力データを自動移行する機能はありません。

## 更新する

1. アプリのファイルを修正します。
2. **必ず `sw.js` の `VERSION` を変更**してください（例: `v1.0.0` → `v1.0.1`）。画面のバージョン表記もindex.htmlで更新します。
3. 変更したファイルを同じリポジトリにアップロードし、公開完了を待ちます。
4. iPhoneでオンラインの状態でアプリを開き直します。新しいファイルの保存が完了したら、画面下の **新しい版に更新** を押します。入力を保存して再読み込みします。

更新通知が出ない場合はオンラインで一度閉じて開き直してください。データ削除を最初の対処にしないでください。読み込み中の更新と混在しないよう、最新版はユーザーの更新操作まで待機します。

## 検証
